LANGKAH 01
Sertakan tanggal atau konteks jika diketahui.
Pratinjau kamera akan muncul di sini.
Kamera hanya aktif setelah kamu menekan “Buka Kamera” dan memberikan izin browser. Pilihan depan/belakang bergantung pada perangkat.
Foto akan dikirim ke server SENTINEL lalu ke model vision yang dipilih untuk dianalisis oleh model vision yang dipilih. Tidak semua model mendukung gambar.
Pengambilan konten URL perlu backend dengan perlindungan SSRF dan validasi domain.
SENTINEL tidak otomatis memperoleh akses ke semua konten platform. API dan izin platform tetap berlaku.
ⓘ Hasil analisis merupakan bantuan pemeriksaan awal. Kesimpulan faktual harus didukung bukti dan sumber yang dapat diperiksa.
